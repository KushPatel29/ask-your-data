# September 7 release verification

## What changed

- Clearer Ask, Data catalog, Trust center, and Project brief navigation;
  one-click starter questions and 39 expandable, executable worked examples.
- Answers present readable paragraphs and result highlights, with SQL and
  calculation evidence available on demand. Model summaries accept only row
  indices; all factual text is rendered from the actual typed result values.
- Free English speech recognition and the male Piper Joe voice remain the
  default. Ordered audio caching, immediate mute changes, repeat-example
  playback, recording cleanup, explicit retry, and visible player fallback
  address intermittent voice failures. Model downloads are verified and atomic;
  inference is serialized with bounded lock waits.
- Authorization now scopes semantic metadata, retrieval descriptions, examples,
  metrics, schema browsing, and session state as well as SQL execution. Additional
  nested-alias, whole-row, positional, renamed-source, and implicit-join bypasses
  have regression coverage.
- Explicit production mode refuses anonymous defaults and requires OIDC,
  a valid policy file, HTTPS identity endpoints, and a configured audit file.

## Reproduce the release checks

Local release evidence (September 7, 2026): **1,063 tests passed, one optional
live-model test skipped**. The final UI/playback subset passed 85 tests after
the last layout edit. Ruff and compilation passed; the HTML audit found zero
markup or token errors and a minimum audited small-text contrast of 4.94:1.
All 39 reference queries matched. A real Joe-to-Whisper round trip preserved
the synthetic test fact. The ordinary planner contract remains 46 matches,
12 required refusals, zero disagreements; the harder model-oriented contract
remains 5 matches, 1 disagreement, and 33 refusals when run through the compiler
alone. Hybrid retrieval recalled every required table on the 39-question set.
These are bounded test-set results, not accuracy claims for arbitrary questions.

Run from the repository root using the project's Python environment:

```powershell
python -m pytest tests/ -q
python -m ruff check .
python scripts/run_planner_eval.py
python scripts/run_retrieval_eval.py
python scripts/audit_ui.py
python scripts/check_readiness.py --voice
```

The voice preflight may download approved model artifacts into their normal
cache. It synthesizes a fixed synthetic-data answer and checks that local STT
preserves its number and subject. Reports contain status/counts, not credentials,
user questions, query results, or recordings. Without `--voice`, preflight does
not download speech models. This checks a checkout, not a running server's health.

## Production boundary

The public deployment is a synthetic-data portfolio demo. Its deterministic
keyless compiler is not a general-purpose LLM; optional model-generated SQL
requires a configured provider. Free speech does not change this distinction.
Browser autoplay and microphone permissions can require a user gesture; the
player and typed input remain available. English is the default STT contract.

Use `.env.production.example` as a configuration reference and run
`python scripts/check_readiness.py --production` before a controlled rollout.
Configuration validation is not production certification: a real IdP/token
integration, database-enforced tenant isolation, protected persistent audit
storage with central forwarding/retention, quotas, load tests, operational
telemetry, backup/restore exercises, and deployment-specific live-model
evaluation still require the operator's infrastructure and evidence. A local
JSONL file alone is not tamper-evident or WORM storage. Streamlit Community Cloud
is not an enterprise availability or data-isolation guarantee.

Optional n8n workflows remain outside the answer/authorization path. No paid
services, unofficial free model proxies, or new third-party data transfers were
introduced by this release.
