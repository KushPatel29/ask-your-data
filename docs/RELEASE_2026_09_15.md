# Release verification — 15 September 2026

## Decision

**GO for the synthetic portfolio demonstration.** The live-model behavioral gate remains
**RUN REQUIRED** after any model provider, prompt, tool, or authorization-context change.
This decision does not approve production use with organizational data.

## What changed

- Added a versioned assurance manifest binding six benchmark/policy suites, their case counts,
  execution modes, release thresholds, five runtime budgets, and five release gates.
- Added a content fingerprint over the manifest and every governed evidence file.
- Expanded the model red-team contract from six mutation-focused prompts to 15 prompts across
  nine threat families, each with a named risk, control, and expected behavior.
- Added an interactive Trust Center release board with benchmark, red-team, role-policy, and
  runtime-cost tabs.
- Added a business case covering stakeholders, current/future state, options, requirements,
  decision rights, UAT, rollout, rollback, and the remaining production evidence.
- Added 28 release-assurance regression tests and reconciled the README badge to the current
  1,128 collected tests (including the release-image security-update contract).
- Closed the release-image security gate by applying available Debian security updates before
  dependency installation; the container scan continues to fail on fixed HIGH/CRITICAL findings.

The skipped test is the credentialed live-model path. It is not silently counted as proof. The
Trust Center therefore carries one open gate and tells the reviewer exactly when to rerun it.

## Scope boundary

Offline CI proves the vendored warehouse, committed reference SQL, deterministic compiler,
retrieval contract, authorization logic, structural verifier, SQL guard, bounded executor, audit
record, and interface contracts. Before a real deployment, the owner must still prove the chosen
identity provider, database-enforced row/tenant policy, durable audit sink, rate limiting, capacity,
recovery, target-provider model behavior, data-owner approvals, and user acceptance outcomes.
